# Upgrade notes - 2.0.0a108 (instructions for Claude)

Nothing to do. Team chats, contacts and settings are kept. If the user has Team contacts, tell them that their
contacts need this version too for edits, "Seen", "writing…" and presence. The session list keeps the user's
choices; the bottom bar of the list is gone, its choices are in the **Display** menu at the top of the list.

Pull request integration is optional and starts paused with no entries. Existing repositories and branches are untouched. Install and authenticate GitHub CLI on the server before using Settings → Pull requests. Only explicitly approved commits may merge after the owner activates the queue; repository CI and rules still apply.

Resident missions are optional: no existing agent starts automatically after this update. Create a draft in Settings → Resident missions, review its plan and limits, and explicitly start it. Active missions keep durable launch keys; recovered or relocated state pauses. Token limits use reported usage and cannot guarantee an exact spend cap.

Optional complete-instance backups: no automatic conversion is required. Existing GitHub memory backups remain selected-file backups. Use Settings → Backup to create an encrypted local archive; its recovery creates a separate copy and requires explicit service activation. Keep its passphrase outside the application.

Optional agent engines: no migration is required. Existing companion roles retain Codex. Select and save another engine in Settings → Companions when desired. Additional engines are trusted local agent extensions; updates do not install or execute an adapter automatically.

Privacy defaults: restart the app after updating to disable native request telemetry. Newly launched Codex turns receive disabled analytics and OTLP exporters automatically; personal Codex settings are not rewritten. Local application statistics and history are kept.

New companion icon: no data migration is required. Reload the updated app to refresh versioned assets. An OS launcher may keep an older installed-app icon until the app shortcut is refreshed by the browser.
